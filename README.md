## 📖 Overview

Creating professional video mockups for apps, websites, and digital products often requires downloading heavy desktop software or navigating complex rendering engines. Mockupreel solves this by bringing hardware-accelerated video rendering and device framing directly into the browser. 

Whether you are a designer showcasing a portfolio piece, an indie hacker launching a product, or a developer presenting UI flows, Mockupreel provides a seamless, zero-install workflow for generating stunning, high-performance MP4 exports.

## ✨ Key Features

- **In-Browser Video Rendering:** Hardware-accelerated, high-fidelity export pipelines utilizing WebCodecs and PIXI.js, entirely within your browser.
- **Dynamic Device Frames:** Beautiful, modern device mockups optimized for both landscape and portrait orientations.
- **Customizable Backgrounds:** Ambient gradients, solid colors, and dynamic styling to make your UI pop.
- **Optimized for Socials:** Export at 60FPS in crystal-clear resolutions perfectly formatted for Twitter/X, Product Hunt, LinkedIn, and Instagram.
- **Zero-Latency Workflow:** Built with a deterministic, event-driven React architecture ensuring a fluid, lag-free editing experience.

## 🧠 Technical Architecture

While this repository serves as a public showcase and issue tracker, the core of Mockupreel is built on a modern, high-performance web stack:

- **Frontend Framework:** React 19 / TypeScript
- **Graphics Engine:** PIXI.js & WebGL for canvas manipulation
- **Video Processing:** Native WebCodecs API with fallback strategies for cross-platform hardware compatibility (Apple Silicon, Windows, etc.)
- **State Management:** Zustand for predictable, high-frequency synchronization without layout thrashing.
